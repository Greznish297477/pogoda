# Погода (Android)
Material You: сегодня, подробный прогноз, достижения с наградами-палитрами, настройки. Погода по 6 источникам (Open-Meteo, MET Norway, wttr.in, DWD ICON, NOAA GFS, ECMWF), обновляется в фоне (WorkManager, раз в 30 мин) и при входе, по вашему местоположению.

## Сборка
1. Установите Android Studio (JDK 17 в комплекте).
2. File → Open → папка Pogoda. Дождитесь Gradle Sync.
3. Подключите телефон (отладка по USB) и нажмите Run, либо Build → Build APK(s).
4. Виджеты: долгое нажатие на рабочем столе → Виджеты → «Погода» (в самом приложении раздела виджетов больше нет).


## Автоматическая сборка APK через GitHub Actions с телефона

В архив добавлен workflow `.github/workflows/build-apk.yml`. Он собирает debug APK при push в `main`/`master` и вручную через Actions.

1. На GitHub создай пустой репозиторий (или открой существующий).
2. Загрузи содержимое архива так, чтобы папка `Pogoda` и папка `.github` оказались в корне репозитория. На GitHub в браузере можно использовать **Add file → Upload files**; если интерфейс не позволяет загрузить папку `.github`, создай workflow-файл вручную по пути `.github/workflows/build-apk.yml` и вставь содержимое из этого архива.
3. Сделай commit в ветку `main`.
4. Открой вкладку **Actions** → **Build Android APK** → выбери запуск workflow при необходимости.
5. Дождись зелёной галочки, открой завершённый запуск и скачай **Pogoda-debug-apk** в разделе **Artifacts**.
6. Распакуй скачанный ZIP на телефоне и установи `app-debug.apk`. При запросе разреши установку приложений из браузера/файлового менеджера.

Это debug APK для тестирования, не подписанный ключом релизной публикации. Workflow пока только собирает APK; он не загружает приложение в Google Play.
